Put your certificate image files here, using these exact names
(or edit the `certifications` array near the top of App.jsx to match your own filenames):

  ceh.png
  security-plus.png
  cisco-intro-cybersecurity.png
  network-security-fundamentals.png

Any image format works (.png, .jpg, .webp) as long as the filename
in App.jsx matches. If a file is missing, the card shows a small
placeholder instead of breaking, so you can add certificates one at a time.
